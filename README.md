# 📧 Intelligent Email Spam Detection using Ensemble Machine Learning

## Overview

Intelligent Email Spam Detection is a Machine Learning-based web application that classifies incoming emails as **Spam** or **Ham (Legitimate)**. The system applies Natural Language Processing (NLP) techniques along with an Ensemble Soft Voting Classifier to achieve accurate and reliable spam detection.

The application is deployed using Flask and provides users with a simple web interface for real-time email classification.

---

## Features

- Real-time Email Spam Detection
- Data Cleaning and Text Preprocessing
- TF-IDF Vectorization
- Ensemble Machine Learning Model
- Flask-based Web Application
- Interactive User Interface
- Fast and Accurate Prediction

## Workflow

1. Load Email Dataset
2. Clean and Preprocess Text
3. Convert Text using TF-IDF Vectorizer
4. Train Multiple Machine Learning Models
5. Build Ensemble Soft Voting Classifier
6. Save the Trained Model
7. Deploy using Flask
8. Predict Spam or Ham in Real Time
